Outlier Remediation Operations

Outliers are never automatically deleted. Any remediation operation produces a new dataset in data/processed/, leaving the raw uploaded CSV completely untouched.

Non-Destructive Lineage
Keep All Outliers (No Removal)

Retain all extreme observations as valid domain records. No file created.

Remove Confirmed Data Errors Only

Drops rows with impossible sentinel codes, negative ages/prices, etc., while retaining legitimate extreme values.

Cap / Winsorize Outliers to Bounds

Clamps extreme values to the lower and upper threshold fences without dropping any rows.

Remove All Outlier Rows

Drops all observational rows that violate lower or upper thresholds across numerical features.
